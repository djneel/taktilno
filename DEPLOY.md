# Развёртывание ТАКТИЛЬНО на хостинге

## 1. Сохранить код в Git

```bash
git init
git add .
git commit -m "ТАКТИЛЬНО — интернет-магазин"
# создайте пустой репозиторий на github.com, затем:
git remote add origin git@github.com:ВАШ_ЛОГИН/taktilno.git
git branch -M main
git push -u origin main
```

Не коммитьте `.env` с реальными паролями (он в `.gitignore`). Все настройки — только через переменные окружения хостинга.

## 2. База данных (бесплатно)

1. Зарегистрируйтесь на neon.tech
2. Create Project → PostgreSQL
3. Скопируйте строку подключения (Connection string) вида
   `postgresql://user:pass@host-pooler.region.aws.neon.tech/dbname?sslmode=require`

## 3. Хостинг Vercel

1. vercel.com → Sign up (через GitHub)
2. Add New Project → Import репозитория
3. Build Settings оставить как есть (Vercel сам определит Next.js)
4. Сразу добавьте переменные окружения (Settings → Environment Variables):

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | строка подключения из Neon |
| `NEXT_PUBLIC_SITE_URL` | `https://ваш-домен.ru` (или временный домен Vercel) |
| `ADMIN_PASSWORD` | ваш надёжный пароль админки |
| `ADMIN_SECRET` | любая длинная случайная строка |
| `YOOKASSA_SHOP_ID` / `YOOKASSA_SECRET_KEY` | обязательные реквизиты магазина ЮKassa |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | когда появятся |

5. Deploy. После деплоя откройте сайт — демо-товары появятся автоматически.

## 4. Применить схему БД (один раз)

На своём компьютере в папке проекта:

```bash
# временно впишите в drizzle.config.json продакшн-URL вместо локального,
# затем:
npx drizzle-kit push --force
# верните локальный URL обратно
```

(Без этого деплой тоже «оживёт»: таблицы создаются командой выше, демо-данные — сами.)

## 5. Домен

Vercel → Project → Settings → Domains → Add → следуйте подсказкам DNS
(CNAME на `cname.vercel-dns.com` или A-запись на IP, который покажет Vercel).
После привязки домена обновите `NEXT_PUBLIC_SITE_URL`.

## Важно про Vercel

- Лимит тела запроса (~4.5 МБ): загружайте фото через админку файлами до ~4 МБ (см. рекомендации по подготовке — их всё равно стоит сжимать).
- Файлы, загруженные через админку, хранятся в PostgreSQL — они переживают любые передеплои.

## Замена изображений на свои

Всё делается в админке, смотрите раздел «Админ-панель» в README.

1. `/admin/login` → пароль администратора.
2. Товары → выберите товар → блок «Изображения».
3. Выберите тип загрузки (Главное / Спереди / Сбоку / Сзади / Сверху / Детали / В руке / Lifestyle / Кадр 360°) → «Выбрать файлы» (можно несколько сразу).
4. Кнопка «Сделать главным» — это фото появится в каталоге, хитах, hero и корзине.
5. Порядок — стрелки «← / →»; первое в списке идёт первым в галерее.
6. Картинки главной, категорий, блока про тактильность и этапов — в «Настройки сайта» (везде есть кнопка «Загрузить»).

### Требования к фото

- Квадрат 1:1, минимум 1200×1200 (лучше 1600×1600) — вёрстку не сломают любые пропорции.
- JPG или WebP, до ~1 МБ (Vercel: до 4 МБ). Сжать: squoosh.app.
- Тёмный фон продукта ляжет в дизайн лучше всего, но это необязательно.
- Для 360°: 12–24 кадра поворота, тип «Кадр 360°», в правильном порядке.

## Оплата ЮKassa

1. Регистрация магазина на yookassa.ru → ЛК → Интеграция → API-ключи → получить `shopId` и секретный ключ.
2. В ЛК задайте URL для уведомлений: `https://ваш-домен/api/payments/yookassa/webhook`, события `payment.succeeded` и `payment.canceled`.
3. Добавьте `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` в Vercel → передеплой (Redeploy).
4. Сделайте тестовый заказ тестовой картой из документации ЮKassa.

ЮKassa — единственный способ оплаты. Пока ключи не заданы, кнопка оформления отключена, а API заказов отклоняет запрос. В чеке каждый товар передаётся отдельной позицией, платная доставка — отдельной услугой.

## Telegram-уведомления

1. В Telegram: @BotFather → /newbot → токен → `TELEGRAM_BOT_TOKEN`.
2. Напишите боту что угодно, затем узнайте id чата (@userinfobot или API) → `TELEGRAM_CHAT_ID`.
3. Добавьте переменные в Vercel → Redeploy. Тест: сделайте заказ.

## VPS-вариант (если Vercel не подходит)

```bash
# Ubuntu 22+, Node.js 20+, PostgreSQL 15+
git clone <репозиторий> && cd taktilno
npm ci
cp .env.example .env && nano .env   # заполнить
npx drizzle-kit push --force
npm run build
npm i -g pm2 && pm2 start npm --name taktilno -- start && pm2 save && pm2 startup
# Nginx: proxy_pass на 127.0.0.1:3000; SSL: certbot --nginx
```

На VPS лимита на размер загрузок почти нет, всё остальное (админка, оплата, уведомления) работает так же.
