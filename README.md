# ТАКТИЛЬНО — интернет-магазин 3D-фигурок

Next.js (App Router) + PostgreSQL (Drizzle ORM) + Tailwind CSS.

## Структура

- `/` — главная (hero, хиты, категории, 360°, процесс, отзывы)
- `/catalog` — каталог с фильтрами, сортировкой и поиском
- `/product/[slug]` — страница товара
- `/cart`, `/checkout`, `/order/[number]` — корзина, оформление, подтверждение
- `/admin` — админ-панель (товары, фото, категории, отзывы, заказы, настройки сайта)

## Админ-панель

Вход: `/admin/login`. Пароль — переменная `ADMIN_PASSWORD` (по умолчанию `taktilno`).
Все товары, фото, цены, остатки, категории, отзывы и картинки главной страницы
редактируются в админке без изменения кода. Загруженные файлы хранятся в БД (таблица `media`)
и отдаются через `/api/media/:id`.

## Интеграции (см. `.env.example`)

- **Оплата ЮKassa** — единственный способ оплаты (`src/lib/payments/index.ts`). До настройки
  `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` оформление заказов недоступно. В фискальном чеке
  товары передаются отдельными позициями, платная доставка — отдельной услугой. Webhook:
  `/api/payments/yookassa/webhook`.
- **Уведомления Telegram** — `src/lib/notifications/index.ts` (место для e-mail/SMS каналов).
- **Доставка** — СДЭК, Ozon и Яндекс Доставка стоят 300 ₽, а при сумме товаров
  от 2 000 ₽ — бесплатно. **Почта России** считает живой тариф по индексу получателя
  (ниже 2 000 ₽ — тариф Почты, от 2 000 ₽ — бесплатно). Самовывоз по адресу
  «Краснодар, ул. Базовская Дамба, 4» с 9:00 до 20:00 бесплатный при любой сумме.
  Конфигурация — `src/lib/constants.ts`, интеграция Почты — `src/lib/delivery/russian-post.ts`
  (публичный тарификатор + сроки, опционально API «Отправка» по договору, трек-номера).

## Разработка

```bash
npm install
npx drizzle-kit push   # применить схему
npm run dev
```

Демо-товары создаются автоматически при первом запуске, если база пуста.
